# Changelog

All notable changes to the Vibe Coding Repository Standard are documented here.

The project follows [Semantic Versioning](https://semver.org/) for the public package. While the major version is `0`, normative details may still evolve between minor releases. Migration notes will accompany changes that affect existing adopters.

## [0.1.0] — 2026-08-15

### Added

- public project identity: **Vibe Coding Repository Standard (VCRS)**;
- approachable README with Mermaid visualizations and a quick-start path;
- white paper explaining the problem, model, adoption stages, limitations, and open-source direction;
- getting-started guide, FAQ, glossary, publication audit, and discovery/launch guide;
- Apache-2.0 license, governance, contribution, conduct, support, security, citation, notice, and roadmap files;
- GitHub issue forms, pull-request template, quality workflow, and Dependabot configuration;
- social-preview and hero assets;
- public-repository validator and tests;
- a clean `standard/` namespace for the original handbook, profiles, prompts, machine profile, template, and validator;
- VCRS standard identifier `VCRS-1` and public-preview version `0.1.0`;
- publication-safe generic examples, neutral project identity, and conservative defaults.

### Preserved

- the original canonical repository guidance;
- four repository profiles;
- Codex-first bootstrap and multi-agent prompts;
- agent, skill, MCP, memory, and hook governance;
- maintenance and pragmatic design guidance;
- the adaptable starter template;
- the dependency-free repository-standard validator and tests.
