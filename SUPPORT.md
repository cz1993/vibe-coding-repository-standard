# Support

VCRS is a community open-source project. Support is best-effort and public by default.

## Use Discussions for

- beginner questions;
- choosing a repository profile;
- adoption planning;
- sharing a sanitized success or failure story;
- comparing agent environments;
- design conversations that are not yet concrete proposals.

## Use Issues for

- reproducible validator defects;
- broken links;
- incorrect or unsafe instructions;
- documentation gaps with a specific suggested improvement;
- concrete standard proposals;
- compatibility reports with steps and evidence.

## Use private vulnerability reporting for

- security vulnerabilities;
- leaked secrets or private data;
- unsafe commands that could cause material harm.

Read [`SECURITY.md`](SECURITY.md) before reporting.

## Protect your information

Before posting publicly, remove:

- secrets and credentials;
- private repository code;
- client or employer names;
- internal domains and IP addresses;
- database connection details;
- customer data;
- personal data;
- screenshots containing browser tabs, paths, account names, or tokens;
- logs that reveal infrastructure or business information.

A minimal reproducible example using synthetic data is more useful and safer than a full repository dump.

## No guarantee

Advice from maintainers or contributors is provided without warranty. You remain responsible for reviewing commands, backups, permissions, legal obligations, security, and production impact in your environment.
